# Icons & Vector System Library

- **Primary Library:** `@phosphor-icons/react` (MIT) + `lucide-react` (ISC)
- **Stroke & Weight Discipline:** Uniform `1.5px` / `regular` technical vector stroke across all interactive controls.
- **Accessibility:**
  - Decorative icons alongside visible labels carry `aria-hidden="true"`.
  - Standalone icon controls (audio toggle, lightbox close, menu trigger) carry explicit `aria-label` and `aria-pressed` / `aria-expanded` states.
