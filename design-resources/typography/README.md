# Typography Resource Library

## Self-Hosted Variable WOFF2 Stack (`/public/fonts/`)
1. **Big Shoulders Display** (`big-shoulders-display-latin.woff2`) — SIL OFL 1.1
   - Role: Monumental brutalist condensed headlines & kinetic marquees.
2. **Unbounded** (`unbounded-latin.woff2`) — SIL OFL 1.1
   - Role: Wide-tracked extended caps (`P R O D U C T I O N S` subtitle, act headers).
3. **Bricolage Grotesque** (`bricolage-grotesque-latin.woff2`) — SIL OFL 1.1
   - Role: High-contrast editorial body and narrative copy (`60ch–72ch` measure).
4. **JetBrains Mono** (`jetbrains-mono-latin.woff2`) — SIL OFL 1.1
   - Role: Strictly reserved for numerical countdown digits, GPS coordinates, frequencies, and RSVP serial hashes.

## Custom AFTERHRS Warped Wordmark System
- Preserves the authentic arched/concave-bottom, heavy black condensed `AFTERHRS` letterforms with blood-red outer halo (`#FF0000`) and luminous cream `P R O D U C T I O N S` lockup from `@afterhrs_prod`.
